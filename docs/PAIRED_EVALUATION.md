# Phân tích Single–Cross theo cặp

Xác minh cùng trace, metadata model/prompt/decoding/schema/budget đã khóa và ID thực gửi khớp projection. Single là tập con theo Order của Cross, so từng event. Mỗi trace evaluation có hai dòng adjudicated, kể cả khi một mode lỗi hoặc thiếu; thiếu bản ghi phải dùng MISSING. Chỉ lấy hiệu số Cross trừ Single khi hai giá trị đều chấm được. Report có per-trace deltas, group ID, fault family, completeness và provider status. Phân tầng completeness theo Cross để giữ cặp xuyên mode và báo phân bố riêng của từng mode.

Báo hiệu số accuracy có điều kiện trên cặp có hai nhãn chấm được và number of scorable pairs. Vì tập này có thể thiên lệch khi hai mode abstain hoặc lỗi khác nhau, trình bày cùng coverage và abstention. Token, cost và latency có summary riêng và hiệu số cho cặp có hai số đo. Không trộn phần trăm failure vào metric đúng/sai có điều kiện.

CI percentile 95% dùng 2.000 bootstrap draws với seed khóa. Resample toàn bộ nhóm, giữ các trace và cả hai mode trong nhóm, sau đó lấy mean trace-level delta. Chỉ bật khi protocol đã khóa `bootstrap_min_groups` dựa trên thiết kế và có đủ nhóm chấm được. Không xem giá trị tối thiểu trong fixture là đề xuất về power. Với ít nhóm hoặc giả định độc lập yếu, để CI null và báo mô tả. Tránh suy diễn ý nghĩa thống kê cho phân tầng mỏng hoặc so sánh hậu kiểm.

Manifest JSON gồm `protocol`, `runs` và `lock_sha256`, canonical JSON theo sorted keys, dấu phân cách compact UTF-8. Mỗi run có run_id, trace_id, group, campaign_id, split, previously_exposed, contexts theo hai mode và ground_truth. Mỗi descriptor có path tương đối và canonical SHA-256. Giữ `labels/` riêng. Review OK cần model_name bằng snapshot đã khóa, config_sha256 bằng canonical hash protocol và đúng event IDs sau budget. Validator phát hiện duplicate ID, group qua split, cùng campaign hoặc signature nhưng tách group, context thay đổi giữa hai mode và tamper. Near-duplicate ngoài signatures chính xác vẫn cần reviewer curator. Một manifest hợp lệ về cấu trúc chưa xác nhận độc lập thực nghiệm.
